# Text anti-slop

这是 `kill-ai-slop` 文本部分的范围缩减与多语言改写。它适用于所有表达性文字，包括文章、故事、文档、产品说明、营销文案、邮件、社交内容和网页 GUI 文案。它不处理颜色、字体、布局、卡片、圆角、动效、图标或按钮样式。

## 先判断，再改写

“像模型写的”不是正则结论。先问这句话是否给出了一个具体事实、动作、限制、受众利益或下一步；再确认命中的表达是不是用户、品牌、引用或行业术语有意选择的。命中只是人工复核线索，引用、用户生成内容、真实状态和有来源的数字可以保留。

## 文本信号

### 1. 口号式翻案和对称转折

模板会先抬高一个空泛对比，再用更大的词收尾，例如英文的 `not just X, it is Y`、`say goodbye to X`，中文的“不是……而是……”或“赋能……”，日文的「単なる X ではなく Y」、韩文的 `단순한 X가 아니라 Y`、西班牙文的 `no es solo X, es Y`。这些句式在真实论证中可以成立，只有在没有新事实、只负责抬价时才改。

改法是直接说作用、条件和后果，再把证据放在附近。不要用另一套漂亮的转折继续做同一件事。

### 2. 空泛的最高级形容词和企业套话

`revolutionary`、`seamless`、`next-level`、`unlock the power`、`effortless` 以及各语言对应的“革命性”“シームレス”“혁신적인”“sin fisuras”等词，只有在有可核验差异时才有用。没有指标、范围或例子时，换成产品实际做的动作。

### 3. 三连口号和碎片鼓点

“Fast. Simple. Yours.” 这类连续短句、三项同构排比和 em dash 戏剧转折，容易制造广告节拍。保留真正需要并列的项目，其他内容合成一句能说明谁做了什么的普通句子。

### 4. 装饰性强调

一段里散落的粗体、彩色短语、全大写、引号金句和 emoji，会让每个词都抢注意力。强调只在它改变含义、标记状态、链接或真实注释时使用。GUI 里的错误、成功和加载状态优先用文字表达，图标只作补充。

### 5. 无来源数字、保证和社会证明

“99.9% 安全”“数千团队正在使用”“十秒完成”都需要来源、测量条件和适用范围。没有这些材料就删掉数字或改成可验证的描述，不替产品创造客户、指标、权限和结果。

### 6. 标题路标和重复说明

“为什么选择我们”“核心优势”“下一步”“一切你需要的”如果只是重复正文，就没有信息。标题说清对象或动作，副文案补条件；删除每个段落前都出现的 kicker、标签和总结句。

### 7. 抽象名词堆叠

把“实现效率提升”“推动能力建设”“进行流程优化”还原为具体动词、对象和结果。英语的 noun stack、日语的汉語連結、韩语的 관료적 명사열거、西班牙语的 `proceder a` 结构也按同一原则处理，但最终句法服从目标 locale。

## 不同表面怎么落地

| 表面 | 文本目标 |
| --- | --- |
| 文章、故事、评论 | 材料推进，判断有来路，段落不靠口号换气。 |
| 文档、教程、帮助中心 | 先说对象和动作，步骤有条件和结果，术语只保留必要部分。 |
| 产品与营销内容 | 说清产品做什么、对谁、在什么条件下有用；少用未经证明的宏大承诺。 |
| 按钮、导航、标签 | 一个控件一个动作，使用目标语言自然的短词。 |
| 状态、错误、空状态 | 说明发生了什么和下一步怎么做，不只显示颜色或 emoji。 |
| 隐私、能力、无障碍文字 | 只承诺实际行为；可见名称、`aria-label`、description 和社交预览共享同一事实。 |

## 工作顺序

1. 先列事实、受众、动作、限制、品牌词和不可翻译词。
2. 用目标 locale 档案筛掉直译、地区词错误和语体混用。
3. 用本文件找模板化表达，逐条确认语境；不要批量删词。
4. 把保留下来的意思改成具体句，补来源、条件或恢复动作。
5. 用 `scripts/check_writing.py` 做确定性检查，再由人工或模型判断自然度。
