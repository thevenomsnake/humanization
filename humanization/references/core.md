# 通用编辑契约

所有任务先读取本文件。通用层只负责事实、来源、能力、隐私、CTA、品牌词、占位符和最小编辑，不规定任何语言的语序、敬语、标点、地区词、翻译腔或节奏。

## 输入账本

在写作或改稿前记录：

- 已知事实、数字、名称、日期、引语、条件和不确定性；
- 每项现实主张的来源，以及哪些内容只来自用户亲历；
- 产品实际具备的能力、权限、限制和恢复路径；
- 收集、使用、保存、删除和分享数据的真实行为；
- 读者应该执行的 CTA，以及产品是否真的支持该动作；
- 品牌词、产品名、术语和不可翻译词；
- 不可改写的 placeholder、变量、链接、标记和转义序列。

缺少的信息会改变事实、承诺或 CTA 时，只问一个聚焦问题。无法取得答案时，缩小主张、保留不确定性，或返回待作者决定，不用漂亮句子填补缺口。

## 事实与来源

- 现实内容只使用用户提供或可核验的事实。不得虚构检索、工具调用、客户、用户反馈、指标、引用、经历或现场细节。
- 来源只能证明它实际覆盖的范围。相关性不能替代因果，先后顺序不能自动写成因果。
- 数字、名称、日期、引语、否定、条件和确定程度在改写前后保持一致。
- 虚构内容可以创造设定、人物和事件，但不能把虚构材料包装成现实来源或用户亲历。

## 能力、隐私与 CTA

- 能力承诺只写产品当前能够完成的动作，不猜测权限、集成、可用性、速度或结果。
- 隐私文字只描述已确认的数据行为，不使用无法证明的“绝不”“完全安全”或同类保证。
- CTA 保持同一个行动、对象、条件和后果。不得为了简洁删掉期限、费用、不可逆结果或恢复限制。
- 跨语言版本可以长度和句式不同，但事实、能力边界、隐私承诺和 CTA 不能漂移。

## 品牌词与占位符

- 品牌词、产品名、批准术语和不可翻译词按输入账本原样保留。
- placeholder、变量名、ICU 参数、URL、markup 和转义不是普通文案。没有明确许可时，不翻译、不改名、不增删。
- 结构化 GUI 资源还要读取 `formats/gui-microcopy.md`，按源文件逐项核对 key、branch 和运行时结构。

## 最小编辑

1. 先通读完整输入，标出不可变信息和已经成立的文字。
2. 只修改影响准确性、理解、任务完成或目标语言自然度的部分。
3. 保留作者已有的立场、正式程度、有效结构和有意义的不确定性，不把所有文字磨成同一种声口。
4. 原文已经自然且符合契约时返回 `no_change`；歧义会改变事实或行动时返回 `needs_author_decision`。
5. 不根据词表或分数声称作者使用了 AI，也不承诺规避任何检测器。

## 范围

语言自然度由一个 locale 档案负责，文字表面由一个 format 模块负责。本 Skill 只吸收 `kill-ai-slop` 中“具体、克制、先判断再改”的文本原则，不包含颜色、字体、布局、卡片、圆角、图标或动效规则。来源项目为 [yetone/kill-ai-slop](https://github.com/yetone/kill-ai-slop)，许可证为 [Apache-2.0](https://github.com/yetone/kill-ai-slop/blob/main/LICENSE)。
